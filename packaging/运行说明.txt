Paper-Agent++ Windows 运行说明

1. 双击 Paper-Agent++.exe。
2. 程序会自动打开浏览器，地址是 http://127.0.0.1:8000。
3. 关闭 exe 弹出的黑色窗口，程序和本地网页服务会一起停止。
4. 模型 API Key 在 config\model.json 中配置；论文来源密钥在 config\system.yaml 中配置。
5. 会话数据库、论文缓存和日志分别保存在 data、data\paper_cache、data\vector_store 和 logs。

注意：这个目录包含当前项目的本地配置。若要把程序发给别人，请先删除 config\model.json 中的个人 API Key，
再让对方复制 config\model.example.json 为 config\model.json 并自行填写密钥。
