Paper-Agent Windows 运行说明

1. 双击 Paper-Agent-Hohai.exe；发布目录中只需要这个 EXE 文件。
2. 程序会直接打开内置桌面窗口，不再调用系统浏览器。
3. 点击窗口右上角关闭按钮时，可以选择最小化到托盘、退出或取消；双击右下角托盘图标可以恢复窗口。
4. 首次使用请注册本地账户，进入“设置”，在预设的 siliconflow_main 中填写自己的硅基流动 API Key 并保存。默认服务地址、三个智能体和 BAAI/bge-m3 嵌入模型已配置好，不需要重新添加。
5. “一图总结”保留原来的硅基流动服务、模型和英文设置，只需填写自己的 API Key。
6. 首页点击与“搜论文”“搜主题关键词”并列的“一图总结”，可直接上传 PDF，或在线搜索并选择论文；全程在当前页面完成。论文结果和资料库中的入口也可继续使用。
7. 精读先识别最多 12 个章节，按顺序逐章阅读，再独立判断核心贡献和局限。每轮自动保存，中断后可以继续。
8. 一图总结会先提取视觉信息，再调用生图服务；生成后可预览和下载图片。重新生成会再次调用用户配置的模型。
9. 模型配置保存在 EXE 旁的 config\model.json；论文来源密钥保存在 config\system.yaml；账户、论文和笔记保存在 data；日志保存在 logs。

本发布版保留默认 Provider、智能体和嵌入模型预设，但不附带个人密钥、账户和历史数据。使用后这些文件会包含你的配置和数据；
如需分发，请使用重新打包的干净目录。打包脚本会把旧发布版放到项目 backups 目录供本机恢复，请勿分发备份。
